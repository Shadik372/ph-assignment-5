# Answer to the Question 1

- **var:** Its value can be **redeclared** which cause unpredictable bugs. If it is used before its line of code, it returns  **undefined** 
- **let:** Its value can be **reassigned**. If it is used before its line of code, the program crashes.
- **const:** Its value **can't be reassigned**. If it is used before its line of code, the program crashes.

# Answer to the Question 3

- **map():** It executes a function on every element and return a new array.
- **filter():** It selects elements based on a condition from an array. then returns a new array.
- **forEach():** It executes a function for each element of an array. but doesn't return a new array.
